# Sitio web — Dr. Enrique Saldaña López

Sitio estático preparado para publicar con GitHub Pages. No requiere compilación ni dependencias locales.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube el contenido de esta carpeta.
2. En el repositorio, abre **Settings → Pages**.
3. Elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda los cambios. GitHub mostrará la URL pública cuando finalice la publicación.

## Estructura

- `index.html`: página principal.
- `assets/images/`: retrato profesional y galería local.

Los estilos, Bootstrap, íconos y fuentes se cargan desde CDN; por ello el sitio requiere conexión a internet para mostrar esos recursos externos.
